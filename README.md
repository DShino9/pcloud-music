# 音楽棚 — pCloud の音楽をブラウザだけで聴く

pCloud Drive のマウントを**一切使わない**。棚も再生もジャケットも、すべて
pCloud の HTTP API 経由なので、マウントが刺さっていても止まらない。
Mac も要らない（GitHub Pages に置いた HTML と iPhone だけで完結する）。

## いま何が動くか

| やること | 使うもの | 費用 |
|---|---|---|
| 入場 | 入口（Cloudflare Workers）で合言葉＋端末の控え | 0 |
| 棚を組む | `showpublink?recursive=1` を1回 | 0 |
| 再生 | `getpublinkdownload` → 音は pCloud から端末へ直接 | 0 |
| ジャケット | 同梱の索引 1510枚。足りなければ iTunes → Deezer → Cover Art Archive | 0 |
| 曲ごとの雰囲気 | 同梱の索引。MusicBrainz → AcousticBrainz で集めたもの | 0 |
| 端末をまたぐ | 索引はアプリに同梱。開くだけで付く | 0 |

## できないこと（試した結果）

**端末に貯めることはできない。** pCloud は端末に中身を読ませない（CORS の許しを
出さない）ので `fetch` が通らず、読めない返事は箱に入れても取り出せない。
入口ごしに読ませる道は pCloud に断られる。仕掛けは残してあるが入口は外した。

**入口ごしに音を配るのは当てにならない。** 三つの壊れ方をした。

| 症状 | 何が起きているか |
|---|---|
| 410 | pCloud はリンクを出した相手にしか中身を渡さない。Cloudflare は行きと帰りで出口が変わることがある |
| 502 | 入口が pCloud から受け取れない |
| error 4 | 正しい mp3 を返しているのに再生側が「この形式は鳴らせない」と言う |

既定では**端末が直に取りに行く**。確実に鳴る。⋯ で入口ごしを試すこともできる。

## レベルメーターの本当のところ

**pCloud から直に流している音は、中身を読めない。** ブラウザは、許しの無い外の音を
解析器に繋ぐと黙って無音にする。だから波形は次の順で取る。

1. 入口ごしに配れているなら、同じ置き場なので**そのまま解析できる**（許可不要）
2. 駄目なら**タブの音**を借りる（一度だけ共有の窓で許可。以後ずっと効く）
3. どちらも駄目なら、曲の進みから作った**飾り**（本物ではない。設定で切れる）

## ジャケットの方針

**サイトを見て回らない。** Amazon や Google 画像検索をエージェントに巡回させると、
1枚あたり数十秒とトークンを食う上に、いくら指示しても寄り道が止まらない。
代わりに鍵の要らない JSON API を決まった順に叩く。1枚 0.3 秒、費用 0 円、LLM は不使用。

1. **iTunes Search API**（1200px。邦楽・洋楽ともここで大半が付く）
2. **Deezer**（JSONP。iTunes が外した洋楽）
3. **Cover Art Archive**（MusicBrainz 経由。日本の編集盤に強い）
4. 手で選ぶ（⋯ →「まとめて見直す」で24枚ずつ。候補が3つ並ぶので押すだけ）

**画像は曲に埋め込まない。** 埋め込むとアルバム10曲を全部書き換えて再アップロード
になり、マウント経由の書き戻しという一番危ない道を通ることになる。
選んだ1枚は索引に URL で持つ。

自動で当てられないものは残る。日本の編集盤やクラシックの寄せ集めは、どの会社の
目録にも無い。そこは手で選ぶしかない。

## 雰囲気

**AcousticBrainz** は録音1件ごとに、明るい・切ない・激しい・穏やか・賑やか・
踊れる を確率で持っている。鍵も要らない。MusicBrainz で曲を突き止めてから拾い、
索引 `雰囲気.json` にして同梱する。

声か楽器かの判定と mood_electronic は**使わない**。歌ものに「歌なし」が付くなど、
はっきり外すことがあった。

MusicBrainz が当たらない盤は、Deezer の BPM と音量から決める。優先の順は
**手で付けた札 → 曲の札の多数決 → 自分で測った値 → 同梱の BPM**。

## 何が誰に見えるか

**このページを開いただけの人には何も見えない。** 入口が合言葉を聞き、通った端末に
だけ 90日の控えを渡す。共有リンクの符号は入口の中にあり、端末には残らない
（画面を出すあいだ記憶に置くだけ）。

控えに残す記録には、合鍵も符号も入れない（長さと番号だけ）。

## 入口を置く

1. dash.cloudflare.com → Workers & Pages → Create → Deploy
2. Edit code に `gate.js` を貼る → Deploy
3. Settings → Variables に入れる（すべて Secret）

| 名前 | 中身 |
|---|---|
| `PASS` | 合言葉 |
| `SIGN_KEY` | 控えに署名する鍵（長い乱数） |
| `PCLOUD_CODE` | 共有リンクの符号 |
| `PCLOUD_LINKPW` | 合言葉付きリンクなら、その合言葉 |
| `APP_BASE` | `https://<ユーザー名>.github.io/pcloud-music` |

## 手元で動かす

    python3 -m http.server 8793

http://127.0.0.1:8793 を開く。入口の無い状態なので、⋯ から共有リンクの符号を入れる。
